# Portal Web SAT Guatemala — Trámites y Servicios en Línea

Prototipo y arquitectura técnica del nuevo Portal Web de la Superintendencia de Administración Tributaria (SAT) Guatemala, desarrollado con **React 19**, **TypeScript**, **Tailwind CSS v4** y **Vite**.

---

## 📚 Documentación del Proyecto

Toda la documentación, hojas de ruta y especificaciones se encuentran organizadas en la carpeta **[`docs/`](./docs/README.md)**:

- 📊 **[Hojas de Ruta y Checklists](./docs/roadmaps/README.md)**: Estado y pendientes de Auditoría UX/UI, Accesibilidad WCAG 2.2 y Mobile First.
- 🏛️ **[Arquitectura de Información](./docs/arquitectura-informacion/README.md)**: Estructura jerárquica de 783 trámites (L1 a L6+), taxonomía ATO y recorridos ciudadanos.
- 🎨 **[Diseño y Normativas](./docs/diseno-normativa/README.md)**: Design System SAT, reglas de interacción, manuales de marca e imagen aprobados.
- 📁 **[Fuentes de Datos Excel](./docs/fuentes-datos/README.md)**: Matrices maestras de trámites y procesos aduaneros.

---

## 🚀 Comandos Rápidos

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
